VesperApp 1.1.0

New
- Live View: real-time view of a KOL's four microphones (or any PC microphone) with a
  multi-channel scope, spectrum analyser and spectrogram; KOL microphone parameters
  (gain, high-pass, decimation filters) adjustable live; optional local processing
  (post gain, Butterworth high/low-pass, mains notch); per-instrument focus and
  pop-out windows; sound-recognition plugin seam with a built-in demo classifier.
- KOL: USB operational modes (Idle / Sampling / Live Audio) switchable from the app,
  and firmware updates directly over the KOL's USB cable (no docking station).
  KOL firmware 1.7 is available in Firmware Upgrades.
- Third-party notices and license texts ship next to the application.

Fixed
- Nanotag firmware flashing failed with "Bad response to bootloader command 0x02/0x03":
  the USB-HID transport could return corrupted replies on Windows. Flashing is now
  verified by the bootloader's CRC, and a tag left in bootloader mode by an
  interrupted update is detected and flashed directly.
- Linux: udev rules now cover the Nanotag bootloader (reinstall 70-vesperapp.rules).
- Windows: the audio library needed by Live View no longer depends on a separately
  installed Visual C++ runtime.

Notes
- Live View audio capture is not available in the 32-bit Windows build.
- Linux: Live View needs the ALSA and JACK client libraries (libasound2,
  libjack-jackd2-0); see the Linux Setup page.
