VesperApp 1.2.1

New
- Vesper / Pipistrelle firmware 1.22: Format offers FAT32 or exFAT (32 / 64 GB), clock base (UTC or local)
  kept by the unit, battery and storage in the Devices panel, up to 150 schedule entries.
- Nanotag firmware 1.40: Clock page time sync and RTC calibration, disk health with a block map,
  configuration read-back and console on the Nanotag page, LOGGER log download, add-on pages
  (TPRH31 / ALS3001D / ProxTit), delayed start for every schedule type.
- Add-ons: DAQ24 (ADS1115) and EEG2 / EMG2 / ECG2 boards (configuration, decoding with the pre-amp
  gain, sensor test); live Lepton thermal view in Device Tests.
- Audio: recording check per run (sample clock, lost audio), optional port-correction and 32.768 kHz
  post-filters, sample-rate advice.
- Microphone check plays its own test tones and verifies them with the PC's microphone.
- Help: Log Codes page with every LOGGER event code and what to do.

Fixed
- Nanotag: Download to the suggested folder did nothing (the tag's ID carried hidden characters);
  "Choose folder…" was not affected. The tag's clock-calibration history is kept.
- Nanotag page: the disk health, configuration and console panels no longer overlap; each scrolls on
  its own, a splitter shares the height, and the console stays where you scrolled to.
- Nanotag download runs off the UI thread (the app froze during a long download), checks every page's
  CRC and reports an incomplete download as such.
- Import copies off the UI thread; a skipped file no longer ends the import; Cancel works.
- ExG: µV scale was half the true value; EXG48 row times.
- IMU decoder: row time from each record's own stamp (stale seconds of firmware up to 1.20 corrected).
- Recordings browser no longer freezes during a GNSS decode.

Notes
- Nanotag GPS: window length / rate are not used (hidden); the motion trigger takes one snapshot per motion.
